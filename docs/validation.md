# 验证范围

## 已执行

- Skill 前置元数据、命名与 UI 配置检查。
- 16 项标准库测试：剧情图结构、资源路径、异常数据、初始化预设、防覆盖及默认开放模板。
- 命令行检查：各预设初始化、剧情样例验证、畸形输入及重复初始化失败路径。
- 文档相对链接与 JSON 语法检查。
- 独立 AI 静态审阅、首轮行为模拟及脚本复测；修复已发现的问题。
- 发布文件清单、凭据模式、本机路径和非预期素材检查。
- 压缩包解压后的干净副本运行测试。

## 分发内容

仅包含重新编写的工作方法、通用模板、原创虚构样例、独立辅助脚本、测试及使用说明。制作时的输入资料及其分析记录不属于发布内容。

## 验证边界

这不等于安装后 AI 制作任意游戏的端到端验证。剧情检查器只理解最小 scene/choice/ending 协议，不检查史实、条件表达式、引擎操作、美术质量、数值平衡或玩家满意度。初始化器只生成工作记录与可选样例，不生成游戏引擎。

行为回归案例见 [behavior-evals.md](behavior-evals.md)。具体作品仍需针对实际玩法与目标平台试玩。
