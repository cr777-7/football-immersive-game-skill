# 足球沉浸式游戏工坊

一个可安装的 Agent Skill：通过分轮提问、可玩样片和持续修改，把用户对足球的各种体验构想变成可玩的作品。

可从用户原创玩法出发，也可探索叙事、动作、战术、经营、解谜、多人协作、空间探索或尚未命名的组合。它们只是例子，不是只能选择的类型。方法与模板服务于用户的构想，不限定作品形式。

## 它会怎样协作

**想法 → 分轮访谈 → 项目简报 → 可玩样片 → 用户反馈 → 扩展制作 → 验收交付。**

内置 58 个可改写的问题起点，并提供新玩法的开放探索方法。先听用户自由描述，每轮只问当前最有用的几项，需要时才给可自定义的选项。你可以详细参与，也可以说“这部分你决定”。已有需求不会反复询问，已认可的内容会被记住；任何阶段都可以要求改剧情、玩法、画风、节奏或界面。

它不要求先选类型，也不固定章数、主角视角、画风、终点或操作方式。广告、抽卡和商业化是可选内容。历史回顾与架空故事有明确边界；生涯模拟包含状态、成长、转会、伤病、退役和数值一致性的设计方法。

## 安装

仓库中可安装的完整目录是 **`skills/football-immersive-game/`**。必须复制整个目录，不能只复制 SKILL.md。

在 Codex 中，可把它放入个人目录 `~/.agents/skills/football-immersive-game/`，或某个游戏项目的 `.agents/skills/football-immersive-game/`。避免在多个位置重复安装同名版本；更新时替换对应目录，先保留自己修改过的版本。

安装后在技能选择器选择“足球沉浸式游戏工坊”，或通过 `$football-immersive-game` 调用。若没有出现，重启客户端检查。也可以让 `$skill-installer` 从你上传后的 GitHub 仓库安装 `skills/football-immersive-game` 路径。

安装目录和调用方式参考 [OpenAI 官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills)，核对日期 2026-09-21。其他支持 Agent Skills 的工具使用其自己的技能目录；本仓库未逐一验证所有宿主。

## 直接开始

```text
$football-immersive-game
我想做一款关于一位足球老将最后一届大赛的沉浸式游戏。
先分轮问我问题，帮我确定方向，再做能试玩的样片。
每轮不要问太多，后面根据我的反馈继续改。
```

```text
$football-immersive-game
做一个中国原创球员从青训到退役的生涯模拟器。
重点是训练、留洋、租借和国家队，手机网页游玩。
我不懂数值设计，请给我选项并解释影响。
```

```text
$football-immersive-game
继续当前项目。保留开场和画风，把第二章改得更有选择感，
让留队或租借影响后面的出场机会，再给我试玩。
```

```text
$football-immersive-game
我已有剧本和参考图。先检查它们与现有代码的差异，
直接做一版完整原型；未说明的设计由你决定，不接广告。
```

例如你也可以直接说：“我想让朋友们扮演一支业余球队，通过手机合作探索球场外的故事，不要先限定玩法，帮我一起发明它。”

开放不意味着承诺任何复杂系统都能一次完成。AI 会先验证核心机制，按实际工具、平台和预算实现；真实联机、空间交互等会单独验证，不用模拟演示冒充完成。

## 包含什么

- `SKILL.md`：核心协作流程与执行要求。
- `references/`：开放玩法探索、访谈、叙事史料、生涯模拟、视听、实现和验收。
- `assets/templates/`：简报、决定记录、事实台账、素材清单、试玩记录、剧情数据样例、生涯模型工作表。
- `scripts/`：创建工作文档、检查剧情图与本地素材引用。仅依赖 Python 3.9+ 标准库。
- `docs/`：通用行为验收案例和验证记录。
- `tests/`：脚本回归测试。

这是制作工作流与辅助工具包，**不是现成游戏引擎**。初始化脚本不会自动生成完整游戏；安装后由 AI 根据用户需求使用所在环境的开发、预览和素材工具执行制作。图像、音频生成服务、联网和发布能力取决于宿主环境，不要求固定模型或付费 API。

## 辅助脚本

在仓库根目录执行：

```sh
python3 skills/football-immersive-game/scripts/init_project.py ./my-football-game --mode open

# 仅在采用本包剧情协议时检查剧情数据（以下为随包样例）
python3 skills/football-immersive-game/scripts/validate_story.py skills/football-immersive-game/assets/templates/story.json
python3 -m unittest discover -s tests -v
```

`--mode open` 为默认，只创建通用工作记录。narrative、career、hybrid 是可选文档预设，不限定游戏类型。目标目录已存在时初始化器退出，避免覆盖作品。剧情检查器只支持本包的最小数据协议，不能替代浏览器试玩、事实核验或模拟器平衡测试。
