# 叙事、选择与足球史料

## 模式决定玩家能改变什么

| 模式 | 可变内容 | 固定/标注边界 |
| --- | --- | --- |
| 历史回顾 | 观看顺序、视角、档案、理解和情感回应 | 已核验赛果与时间线固定 |
| 历史中的虚构角色 | 原创角色行动与关系 | 不把补写当作真实人物史料 |
| 架空分支 | 从分歧点改变比赛或生涯 | 标明分歧点及“架空剧情” |
| 原创生涯 | 系统允许的职业路径 | 世界规则自洽，比赛是模拟结果 |
| 线性纪念作品 | 阅读节奏、回看、资料探索 | 不承诺玩家能改变结局 |

## 从材料到剧情

1. 列事件时间线、人物关系和资料冲突。原稿与发布版分开标记，不因文件名含“最终”就自动采用。
2. 写一句主题命题，例如“一个失去首发位置的人如何重新定义价值”。避免“伟大球员辉煌一生”这种没有冲突的主题。
3. 挑选能推动主题的事件，按情绪和因果组织，而非平均分配年份。章数由时长与内容决定。
4. 给每章一个不可替代的功能：建立愿望、第一次代价、关系破裂、主动选择、结果与回望。
5. 场景卡写清时间/地点/视角、欲望、障碍、玩家动作、后果、事实依据、画面与声音。
6. 选一个可回收的物件/动作：手套、旧球衣、替补席、系鞋带、走过通道。结尾改变它的含义，而不是重复标语。

情绪节奏用“紧张 → 呼吸 → 冲突 → 峰值 → 余韵”，不让每页都尖叫。首屏给具体处境与疑问；结尾回收用户自己的选择，避免千人一面的赞美。

手机主线每屏先以 1–3 句短句试排，留断句和停顿；这是起点，不是机械字数规则。复杂战况用比分板、时间线或展开档案解释。对白和独白让人说话，不写连续百科段落。

## 选择必须有作用

为每项选择填写：玩家知道什么、为什么两边都合理、立即付出什么、状态如何变化、何处回响。可以汇流，但汇流前后必须保留差异；纯换一句台词的选择可以作为表达，但不要宣称为重大分支。

将四种交互分开：知识题检验事实、立场选择表达态度、战略选择权衡代价、探索操作控制信息。立场不同不等于答错，结局措辞尊重玩家不同的判断。

结局条件从可达路径计算。若显示归一化分数，明确原始上下限和换算，不靠截断掩盖计分设计的不一致。低分或失败结局也要完整、有尊严。情感作品优先人物关系或主题维度，避免用单一分数替代复杂的情感回应。

分支范围控制：默认先做一个有意义的分歧、两个即时结果、一次后续回响，再决定是否增加并行章节。每增加结局列出额外文案、素材和测试量。

## 事实台账

`facts.csv` 每条记录包含 id、主张、事件日期、来源标题、URL/本地出处、访问日期、状态、适用节点、补充说明。状态使用 `verified`、`unverified`、`conflicting`、`fictional`。本包空模板不表示已查证。

需核对：对手、赛事届次和阶段、年龄、场地、比分、进球顺序、球衣、教练、奖项全名。区分常规时间、加时、点球大战；区分赛事最佳球员奖与其他同名奖项；俱乐部归属按赛季而非当前印象。

查真实事件时优先官方赛事/俱乐部档案，再交叉对照可靠报道。争议信息并列来源，不擅自拼成肯定结论；时效事实需实际检索。用户资料可做线索，不能自动视为权威。

引用台词保存可核验出处。补写内心独白标作戏剧化演绎；未来赛事或改变现实结果的分支标作架空。没有联网能力时将待核事实列出，使用原创/明确标注的占位内容推进，不捏造来源。

“报纸”“弹幕”“新闻截图”若为制作素材，应标明模拟版面或剧情演绎。AI 绘图不是历史现场照片。素材的授权状态和事实的可信度是两个字段，不互相替代。

## 最小场景卡示例（全为虚构）

- 场景：18 岁的林川在训练结束后收到外地球队的租借邀请。
- 冲突：留队能保留熟悉关系，租借能争取出场但需要适应陌生环境。
- 选择 A：留队竞争 → 教练信任 +1，出场机会暂缓；后续触发老队友对话。
- 选择 B：外出租借 → 适应压力 +1，新队出场机会增加；后续触发首次独自客场。
- 共同回收：数年后重新面对这件旧球衣，两条路径的回忆不同。
- 画面：空训练场、收好的球衣、手机邀请信息；声音：关灯声后留一拍静默。
