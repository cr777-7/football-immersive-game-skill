# 实现约定

## 适用范围

本文件以轻量网页叙事的实现经验为主，不是所有足球游戏的架构标准。非网页项目沿用其引擎和交互约定；实时、多人、空间或实体结合项目先按 [开放玩法探索](open-design.md) 确定模型，再读取适用部分。没有场景切换就不强设剧情节点，没有分数就不强设评分。

## 分离内容、规则和呈现

新建轻量网页作品可采用 `game/` 内容数据、`src/` 引擎与 UI、`assets/` 资源、`design/` 创作资料、构建后的 `dist/`。已有项目保留其合理结构。

UI 从单一状态渲染；切换场景集中走 transition。节点有稳定 id，不用数组下标作为跨版本存档依据。小游戏 SDK、广告、分享、统计封装成可替换适配器；普通浏览器缺失这些功能仍可完成核心体验。

## 最小剧情数据协议（仅本包检查器）

参考 [story.json 样例](../assets/templates/story.json)。顶层：`schemaVersion: 1`、`start`、`nodes`，可选 `assets`。每个节点必须有唯一 `id`、`type`、`text`；本协议类型为 `scene`、`choice`、`ending`。

- scene：一个 `next` 目标。
- choice：至少两个选项，每个有节点内唯一 `id`、`label`、`next`，可选 `effects`（状态键到有限数值的增量，整数须在 JavaScript 安全整数范围 ±(2^53−1) 内）。
- ending：终点，不带 next/options。
- 节点可选 `assetIds` 数组，引用顶层 assets 中的 id。
- 资源必须有唯一 id 与项目根目录内的相对文件 path；本检查器不接受外网 URL 或 data URI。
- 其他字段可承载 chapter/pov/factIds 等元数据。conditions 等扩展并不被检查器理解；必须增加运行时测试。

这是小型叙事图协议，不是强制完整引擎。要实现 panel/comic/hero/archive 或条件路由时，可将展示组件放到 scene 的元数据，或扩展实际模型和验证器；不要只改 JSON 类型而假定旧检查器支持。

检查器会报告重复 id、缺失目标、缺文件、越界路径、不可达节点、无结局出路。可达环路给警告；环路可能合法，但人工检查是否能退出。静态存在出口不等于所有条件下能退出。

## 交互与异步

- 打字机第一次点击补全文字，第二次点击前进；选项、弹窗和按钮不能冒泡导致多次前进。
- 使用明确状态 reading/choosing/overlay/transitioning/ending 或等价设计，避免互相矛盾的布尔标志。
- 每次转换生成 transition token；异步图片加载完成后检查 token，防止旧图片覆盖新场景。
- 所有自动推进定时器、动画、打字、音频 cue 在离开节点时取消。不要只清除名字相似的另一个 timer。
- 选择、领取、结算保证至多一次；重复点击不重复加分。弹窗关闭是关闭还是前进，语义明确。
- 用户输入、角色名和动态文本用 textContent 或经过安全处理的模板，不直接拼入未转义 HTML/事件属性。

## 存档与重开

包含 schemaVersion、contentVersion、nodeId/回合、玩家状态、选择历史、随机数状态、音量设置。读入后验证类型、范围和节点存在性；提供迁移或明确重置，不静默读成错误剧情。

存档不可用（隐私模式、配额等）时允许本局继续并说明限制。重新开始清理本局状态和 pending timers，保留用户希望保留的设置。返回前台或浏览器回退不能无条件 reload 导致进度丢失。

## 移动端与可访问性

实际预览 320/375/430px 宽和桌面，处理安全区、动态视口高度和长内容滚动。点击区有足够尺寸；选择可键盘操作，弹窗管理焦点；不只用颜色传达利弊。提供跳过打字、合理字号、静音和减弱动画。与用户约定的目标浏览器或内置 WebView 需要实测，桌面截图不能替代。

## 可选商业化与分享

只在用户明确需要时接入。使用平台当前官方文档和配置，不复制示例项目的私有 SDK 地址或凭据。

广告状态区分 unavailable/requesting/completed/cancelled/error/timeout。只有平台认可的 completed 才记为广告成功；超时可给体验兜底，但不能伪报观看完成。奖励回调幂等；不把用户卡死在无法展示广告的环境。

分享优先支持系统可用能力，并提供下载图/显示图片的降级。canvas 导出检查字体加载和跨域图片污染；结果图与游戏共用 summary。不能假设所有平台能直接分享，也不能捏造玩家百分位。

前端只保留可公开配置。密钥由受控服务端环境读取；日志和发布包不携带认证信息。无需外部服务的单机游戏不要为了“AI 游戏”强接在线模型。
